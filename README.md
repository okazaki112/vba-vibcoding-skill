## §02 怎么工作

四步闭环。每步有门禁，门禁不过，下一步免谈。

1. **需求分析** —— 判定交付分支；需求含糊先问，不瞎猜。　`门禁：目标文件明确，或声明新建`
2. **代码生成** —— 按 10 条现代准则写 VBA，过 19 道质量门禁。　`门禁：清单全过 + 读回证据`
3. **建簿与注入** —— 没给文件就新建带测试数据的 .xlsm；给了就先备份再注入。　`门禁：write 与 list 双回执 success=true`
4. **运行与交付** —— run 宏、核对输出，不对就改（最多换三种方法）。　`门禁：输出符合预期 + 命令证据`

## §03 三种交付

- **默认（未指定文件）**：新建 .xlsm，写入 20 行业务测试数据（金额=数量×单价），注入宏、实跑验证。**——打开就是成品。**
- **指定文件**：先 export 备份同名模块，再注入。**——先备份，再动手。**
- **明确只要代码**：给 .bas 文件和 Alt+F11 粘贴步骤，不注入。**——质量不打折。**

## §05 命令一览

| 命令 | 用法 | 说明 |
|------|------|------|
| create | `create "新文件.xlsm" [工作表] [行数] [列数]` | 新建 .xlsm 并写入测试数据，默认 20 行 6 列；已存在拒绝覆盖 |
| list | `list "文件.xlsm"` | 列出模块：名称、类型、行数 |
| read | `read "文件.xlsm" "模块名"` | 读模块源码 |
| write | `write "文件.xlsm" "模块名" "代码.bas"` | 写入或覆盖模块，自动保存 |
| delete | `delete "文件.xlsm" "模块名"` | 删模块 |
| run | `run "文件.xlsm" "宏名" [参数...]` | 运行宏，带回执 |
| export | `export "文件.xlsm" "模块名" "备份.bas"` | 导出备份 |
| import | `import "文件.xlsm" "模块.bas" [新名称]` | 导入模块 |

所有命令返回 JSON，以 `success` 字段判定成败。完整 API 见 [docs/API.md](VBA智能编程助手/docs/API.md)。
