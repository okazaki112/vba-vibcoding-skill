# 验收用例

## 用例 1：默认新建带测试数据工作簿

### 输入
用户说「帮我写个宏，把某列数据去重统计」，未指定任何 Excel 文件。

### 期望输出
新建的 .xlsm 工作簿：含测试数据工作表、表头与多行测试数据；去重宏已注入并运行；交付报告含路径与执行摘要。

### 判定点
- [ ] 生成了新 .xlsm 文件（create 返回 success=true）
- [ ] 工作表含表头且测试数据不少于 10 行
- [ ] 注入模块出现在 list 结果中（success=true）
- [ ] run 命令 success=true 且输出符合去重预期
- [ ] 交付报告含文件路径、模块名与执行摘要

## 用例 2：指定已有工作簿

### 输入
用户给出已有文件路径（.xlsm）并描述新功能需求。

### 期望输出
不新建文件；同名模块注入前已 export 备份；注入后 list 可见；run 验证通过。

### 判定点
- [ ] 未新建工作簿，改动发生在用户指定文件
- [ ] 注入前对同名模块执行了 export 备份
- [ ] list 结果包含新模块（success=true）
- [ ] run 输出符合需求预期

## 用例 3：仅代码分支

### 输入
用户明确说「只要代码，我自己粘贴」。

### 期望输出
.bas 代码文件与 Alt+F11 手动粘贴步骤；不调用 write/run。

### 判定点
- [ ] 交付 .bas 文件且内容通过 19 项质量检查
- [ ] 附 Alt+F11 手动粘贴步骤
- [ ] 未执行 write 注入与 run 运行
